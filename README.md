# 🐍 Python IT Automation

A collection of practical Python utilities developed to automate common IT support, systems administration, networking, and cybersecurity tasks.

This repository was created to strengthen hands-on Python skills while solving real-world IT problems through scripting and automation. Each project focuses on practical use cases commonly encountered by Help Desk Technicians, IT Support Specialists, Junior Systems Administrators, and Infrastructure Engineers.

---

## 🚀 Features

- 🖥️ Windows System Administration
- 🌐 Networking Utilities
- 🔒 Cybersecurity Tools
- ⚙️ IT Process Automation
- 📊 Reporting & Monitoring
- 📁 Backup Utilities
- 🧩 System Diagnostics

---

# 📂 Repository Contents

## 🖥️ System

### 📌 SystemInfo.py
Displays detailed system information including:

- Computer Name
- Operating System
- CPU
- Installed RAM
- Disk Usage
- Free Disk Space

---

### 📌 SystemHealthDashboard.py

A real-time monitoring dashboard displaying:

- CPU Usage
- Memory Usage
- Disk Usage
- Running Processes
- Network Connectivity
- System Uptime

---

## 🌐 Networking

### 📌 PortScanner.py

Simple TCP Port Scanner that scans common ports including:

- HTTP
- HTTPS
- SSH
- FTP
- RDP
- DNS
- SMB

---

### 📌 PingSweep.py

Scans an entire subnet to discover active hosts.

Features:

- ICMP Ping
- Hostname Resolution
- CSV Export
- Network Discovery

---

### 📌 DNSLookup.py

Performs DNS lookups including:

- IPv4 Resolution
- IPv6 Resolution
- Reverse DNS Lookup
- Hostname Information

---

## 🔒 Security

### 📌 PasswordGenerator.py

Generates strong random passwords using Python's `secrets` module.

---

### 📌 PasswordStrengthChecker.py

Evaluates password strength using:

- Length
- Uppercase Letters
- Lowercase Letters
- Numbers
- Symbols

---

### 📌 FileHasher.py

Calculates file hashes using:

- MD5
- SHA1
- SHA256

Useful for file integrity verification and cybersecurity workflows.

---

## ⚙️ Automation

### 📌 BackupUtility.py

Creates folder backups while preserving directory structure and timestamps.

Ideal for:

- User Profile Backups
- Data Migration
- Disaster Recovery

---

### 📌 LogAnalyzer.py

Reads log files and summarizes:

- Errors
- Warnings
- Information Messages

Supports troubleshooting and system diagnostics.

---

### 📌 CSVReporter.py

Analyzes CSV files and generates reports including:

- Row Count
- Column Summary
- Missing Values
- Duplicate Records
- Sample Data
